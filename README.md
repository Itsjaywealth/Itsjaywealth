## How I build

- **Product and web:** typed web applications, APIs and native mobile apps, designed and shipped as one product
- **Data:** relational databases with migrations, row-level access rules and tested backups
- **Payments and commerce:** checkout, wallets, signed webhooks and daily reconciliation
- **AI and automation:** RAG pipelines, tool-using agents, approval-gated actions and event-driven integrations
- **Infrastructure:** managed hosting, edge security and automated deploys from reviewed pull requests
- **Quality:** browser and contract tests in CI, secret scanning, monitoring, backups with restore checks

Secrets, customer data and production configuration never go into Git. Public repositories are scanned across their full history before they are published.
