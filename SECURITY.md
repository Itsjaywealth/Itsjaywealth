# Public Profile Repository Security

This repository is intentionally limited to public professional-profile content.

Do not commit credentials, API keys, access tokens, private keys, production configuration, customer data, private operational logs, or other confidential BrandVerse Ventures information.

The profile README is the canonical public project summary. Production repositories and operational configuration remain private unless they have been separately reviewed and approved for public release.

For security-sensitive reports, use the private vulnerability reporting flow provided by GitHub when available.
